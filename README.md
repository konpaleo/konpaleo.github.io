# Freelancer-style Jekyll portfolio

This is a starter GitHub Pages portfolio for `konpaleo.github.io`, built with
Jekyll and inspired by the Freelancer theme. The rendered pages use HTML files
with Liquid front matter rather than Markdown page sources.

## Run locally

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open <http://localhost:4000> in your browser.

## Customize

1. Change your name, email, role, location, and site description in `_config.yml`.
2. Replace the sample projects in `_data/projects.yml`.
3. Add project images to `assets/images/` and update each project's `image`.
4. Replace placeholder copy in `index.html`, `about.html`, and `projects.html`.

The `_site/` directory is generated by Jekyll and is intentionally ignored by
Git. GitHub Pages builds the site from the repository source automatically.
